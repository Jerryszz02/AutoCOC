# 战前候选规则

`air-prebattle-v1.json` 是首批空军候选比较条目，适配既有严格 `load_guides` JSON 格式。配置 `vision_agent.guide_file = "assets/guides/air-prebattle-v1.json"` 后，在搜敌前加载；相对路径以配置文件目录为基准。默认配置不启用，规则不生成新坐标、数量或动作。

目前包含雷龙可见布局、龙宝宝清边顺序、法术目标证据三项。条目按当前已识别兵种筛选，只用于已验证的有限候选。客户端和模型准入仍由模型包及布局档案核验；这些文字没有经过实战效果验收，不能作为通用配兵、连锁范围、技能时机或胜率保证。

机制来源：Supercell 的 [Meet The Electro Dragon!](https://supercell.com/en/games/clashofclans/blog/news/the-electro-dragon-is-here-to-wreak-devastation/)（2018-06-08，2026-10-15 查阅）说明雷龙能连锁命中多个目标。这里仅采用这个定性机制，不采用历史等级、伤害、距离数值，也不推断当前版本的平衡参数。清边顺序和法术条目是项目自身的条件规则与能力约束，不是从该页面引出的官方打法。

`visible_layout` 保存当前模型已检测建筑的类别、框、置信度及候选入口到最近已检测同类建筑的屏幕距离。它绑定原帧、模型和冻结计划哈希，进入决策输入与执行回执。未检出、隐形陷阱、吹风机朝向、等级、剩余生命值、射程及格子比例均保持未知。局部模型只提供其支持类别；不得把类别之外的建筑当作不存在。
