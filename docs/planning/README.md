## 维护方式

实现阶段推进时，同一 PR 更新受影响的子计划和[当前进度](../PROGRESS.md)；执行模式改变同步主计划，模型包契约改变同步接口文档。数据、模型、代码、离线结果与实战分别记版本和状态。

文档改动至少检查 `git diff --check`、规划索引覆盖、本地链接/锚点、引用的代码路径和可运行命令。未随仓库发布的历史报告单列为本地证据，不要求新克隆伪造缺失产物，也不把文档检查通过当作产品验收。
