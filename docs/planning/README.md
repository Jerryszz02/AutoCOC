# AutoCOC 规划文档索引

- 主题：战前分析、快速连续投放、视觉素材采集与模型训练。
- 工作模式：核对既有计划，细化可交接的采集/标注与训练/导出方案；本轮只修改规划文档。
- 更新与证据核对日期：2026-09-27。

- 本轮核对的代码基线：`b4eb3960a0bb7a6f7c653edfc239c88415df752a`；初版规划基线 `1ae2ae2601eaf8398735d384586667e3d4484d82` 保留为历史。

AutoCOC 是本地运行的游戏日常助手，已有截图、局部识别、策略执行、数量核验和任务报告代码。此次目标是利用战前约 30 秒的准备窗口看清阵型并编排动作，开打后由本地程序连续执行；战中“截图到完整动作 ≤0.5 秒”属于后续尝试目标。

本目录保留需求与设计基线。当前实现以对应提交的代码为准，运行效果以带版本、输入和时间的实际报告为准。准备期调度、冻结投放、本地模型加载、Jev、GUI 与报告已有代码和历史离线测试；模型权重与实际效果未验收。本轮没有重跑产品测试、连接训练机器或启动实战。主工作区已有 146 张本地候选截图，尚未正式标注/拆分，不能当作可直接训练的数据集。

最新补充要求从第一轮就积累前戏与主力时序素材，以减少后续补训返工；模型训练、接口接入与实战启用分别验收。
