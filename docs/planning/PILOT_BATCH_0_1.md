## 建筑输出合同

最小类别固定为 `town_hall`、`air_defense`，taxonomy 稳定 ID 分别为 1、3；模型导出的连续类别顺序固定为 **0 → town_hall、1 → air_defense**，两种 ID 不混用。原图像素框经 `battle_layout.describe_visible_layout()` 缩放到 baseline 坐标，形成每类可见建筑及入口距离，传入 `prepared_battle` 的有限候选。距离是屏幕像素，不是射程；未检测到意味着未知，不是不存在。

现有核心、入口和部署边界工具可复用，但没有通过正式门槛的新版双类 B 模型。`vision_agent.enabled=false`、`jev_enabled=false`，模型不参与本轮游戏输入。主村视角不充当敌村最小缩放证明；每张敌村候选须单独记录相机/缩放和合法边界状态，未知就保留未知。
